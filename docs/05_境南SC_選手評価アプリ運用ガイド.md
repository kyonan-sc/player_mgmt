# 境南SC 小学3年生｜選手評価アプリの使い方

## コーチのみなさんへ

このアプリでやりたいことは、一人ひとりのプレーを記録し、次の練習で何を伸ばすかをコーチ同士で共有することです。特にCクラスでは、今つまずいている場面を見つけ、本人が「前よりできた」と実感できる機会を増やしたいです。

A・B・Cは、その時点のプレーと育成課題をもとにしたチーム編成です。公式戦では勝利を目指してメンバーを選びます。練習や練習試合では、Cクラスの選手にも、ボールに関わり、練習したプレーを試せる機会を計画してつくります。クラスを見直すときは、複数の練習や試合で見られたプレーをコーチ間で持ち寄ります。クラスが変わらない時期も、できるようになったプレーを本人に具体的に伝えます。

### 練習から振り返りまで

1. **見たプレーを残す。** 練習や試合のあと、日付・場面・行動を短く記録します。「積極性が足りない」よりも「ミニゲームで、味方が顔を上げたときに横へ動いてパスを受けた」のように、別のコーチにも場面が伝わる言葉を使います。観察できていない項目は、次に見る場面を決めます。
2. **次の目標を一つ決める。** 前回の記録と見比べ、本人が次の練習で試せる行動を一つ選びます。本人にも「次はどっちをやってみたい？」と聞いて、目標を一緒に決めます。
3. **その行動を試せる練習を用意する。** 目標が「パスを受ける場所に動く」なら、まずは守備をつけずにパスコースをつくる練習をし、次に少人数のゲームで試します。コーチは成功した瞬間に「今、横に動いたからパスが通ったね」と伝えます。
4. **もう一度見て、次の練習を決める。** 年に複数回の評価で履歴を見返し、どの場面で同じプレーができるようになったかを確認します。うまくいかなければ、距離や相手のプレッシャーを調整して、試せる場面をつくり直します。

### 記録例

| 記録すること | 記入例 |
|---|---|
| できた場面 | ３対１で、味方がボールを持ったときに横へ動き、パスを２回受けた。 |
| 次の目標 | ミニゲームで、味方がボールを持ったら、相手のかげから横に出てパスを受ける。 |
| コーチが用意する場面 | 練習の最初に３対１で試し、そのあと３対３でも同じ動きを試す。 |
| 次回の振り返り | ３対３でも横に動いてパスを受けられた。次は受ける前に、進める方向を見てみる。 |

保護者と本人には、その子の「最近できたこと」「次に試すこと」「コーチが練習で用意すること」を個別に伝えます。

## 保護者のみなさまへ

境南SCでは、練習や試合で見られたプレーを記録し、お子さんが前よりできるようになったことと、次に取り組むことをお伝えします。たとえば「味方がボールを持ったとき、横へ動いてパスを受けられた」というように、実際の場面をもとにお話しします。

A・B・Cは、その時点でのプレーと練習の課題をもとにした編成で、定期的に見直します。公式戦では勝利を目指して出場メンバーを選びます。練習や練習試合では、一人ひとりが今の目標を試せる機会をコーチがつくります。出場やクラスについてご質問があれば、どんな場面を見て判断したか、これから何を練習するかを個別にお伝えします。

ご家庭では、練習のあとに「今日、前よりできたことはあった？」と聞いていただけるとうれしいです。本人が見つけた小さな変化も、次の練習につながります。

## 子どもたちに伝える言葉

サッカーで、前よりできるようになったことをコーチといっしょに見つけよう。つぎの練習でやってみたいことも、一つ決めよう。むずかしかったら、やりやすい練習からいっしょにやってみよう。

> この前、味方がボールを持ったとき、横に動いたらパスが来たね。あの動き、よかったよ。つぎのミニゲームでも、相手のかげから横に出て、パスをもらってみよう。まずはコーチと練習しよう。
