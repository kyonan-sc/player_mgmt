### 1.2 技術的制約

| No   | 制約                                                                                                     | 対応                                                                                                                                      |
| ---- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| T-01 | GAS Web App は `script.google.com` → `script.googleusercontent.com` へ 302 リダイレクトする              | `fetch(..., { method: 'POST', mode: 'cors', credentials: 'omit', redirect: 'follow' })` で追従。Phase 0 で Chrome/Safari/iOS Safari 検証  |
| T-02 | 独自ヘッダーや `application/json` はプリフライトを誘発し、GAS は OPTIONS に応答できない                  | `Content-Type: text/plain;charset=UTF-8`、ID Token はボディに格納                                                                         |
| T-03 | GAS には RSA 署名「検証」用の組み込み API がない（`Utilities.computeRsaSha256Signature` は署名生成のみ） | 純粋JS実装の `jsrsasign` を採用。WebCrypto 依存の `jose` 等は GAS で動作しないため不採用。GAS 実機での動作確認を Phase 0 の必須項目とする |
| T-04 | GAS V8 には `window` / `process` / `Buffer` / `TextEncoder` 等がない                                     | esbuild で IIFE バンドルし、`globalThis` 経由で `doGet` / `doPost` を公開。依存ライブラリは GAS 実機スモークテストで確認                  |
| T-05 | Google Identity Services の ID Token は約1時間で失効し、リフレッシュ不可                                 | メモリ保持のみ。失効時は再ログインを要求（`UNAUTHENTICATED` 受信時にログイン画面へ）                                                      |
| T-06 | Sheets はトランザクションなし・同時実行数制限あり                                                        | `LockService.getScriptLock()` で書き込みを直列化。確定処理は upsert で冪等・再実行可能にする                                              |
| T-07 | Sheets は `2026-06-01` 等を日付型へ自動変換する                                                          | シート全体をテキスト書式に設定。読み取り時に Date 型が来た場合も ISO 文字列へ正規化                                                       |
| T-08 | GitHub Pages はサブパス配信                                                                              | Vite `base: '/player-assessment/'`、HashRouter                                                                                            |

## 3. アーキテクチャ方針

```
apps/web  (React SPA, GitHub Pages)
  └─ lib/api-client.ts ── fetch(text/plain, cors) ──▶ GAS doPost
                       └─ (mock) MSW ──▶ @kyonan/gas/core + MemoryTableStore
apps/gas  (GAS V8)
  entrypoints/ doPost → api/dispatcher → auth(verifier) → services → repositories → infrastructure(TableStore)
packages/shared  型 / Zod スキーマ / 定数 / 評価計算（純粋関数）
```

- `TableStore` インターフェース（`SheetsTableStore` / `MemoryTableStore`）でデータ層を差し替える。
- `IdTokenVerifier` インターフェース（`GoogleIdTokenVerifier` / `MockIdTokenVerifier`）。GAS エントリーポイントは Google 版のみを import する。
- フロントエンドは `features/*/api.ts` に TanStack Query のフックを集約し、コンポーネントから fetch を直接呼ばない。

## 5. 本番適用の判定基準（セキュリティ）

- [ ] 実 GAS 環境で権限外操作が拒否されることをスモークテストで確認
